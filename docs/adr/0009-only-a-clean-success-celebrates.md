# Only a clean success celebrates, and every other end names itself

Spindle celebrates a finished run only when it closed done, no MSP shipped as a draft pull request and the latest lighthouse run's verdict is green; every other end shows a plain finish whose word, headline and reasons name how it ended, such as Stopped, Draft or Abandoned, and only a closed-done or cleaned run draws its bar and stage rail fully done. A closed-done thread alone would celebrate runs that shipped a blocked MSP as a draft or failed lighthouse, and the band's old Done pill read the same for a stopped run as for a success, which hid the outcome the owner most needs to see.

Status: accepted

## Consequences

The celebration plays once, only when spindle sees the run finish during the session, ends within 3 seconds, uses its own one-shot hop rather than the crew's walking CSS, and is still under reduced motion; the finish settles five seconds after spindle first sees it, and a finished bar no longer twinkles, so nothing moves after the celebration (WCAG 2.2 success criteria 2.2.2, 2.3.1 and 2.3.3). A new lifecycle state needs its own finish word and headline, and a change to how the pipeline marks a draft or lighthouse names its verdicts must reach the gate.
